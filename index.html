Lançar saldo do Ponto

Saldo apurado no sistema de Ponto — é ele que forma as horas disponíveis para compensar. Aceita formato HH:MM (ex: 09:24) ou decimal (ex: 9.4). Use sinal negativo para saldo devedor.

Importar saldos do Ponto

Uma linha por colaborador, no formato NOME ; HH:MM. Já preenchido com o fechamento de julho/2026, positivos e negativos. Os nomes são convertidos automaticamente para o cadastro padrão.

Padronizar nomes no banco

A tela já exibe os nomes unificados. Esta ação grava a correção no banco, deixando o histórico limpo. Nada é apagado — apenas o campo do nome é reescrito.
